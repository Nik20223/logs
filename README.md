# Анализ лога веб-сервера (access.log)

Скрипт `log_analyzer.py` анализирует логи веб-сервера в формате

```
%h - - %t "%r" %s %b "%{Referer}" "%{User-Agent}" %d
```

где:

- `%h` — IP-адрес удалённого хоста;
- `%t` — время получения запроса;
- `%r` — тип запроса, его содержимое и версия протокола;
- `%s` — код состояния HTTP;
- `%b` — количество отданных сервером байт;
- `%{Referer}` — URL-источник запроса;
- `%{User-Agent}` — HTTP-заголовок с информацией о клиенте;
- `%d` — длительность запроса в миллисекундах.

## Требования

Только стандартная библиотека Python (3.7+). Внешние зависимости не нужны.

## Запуск

Скрипт принимает путь к **файлу** лога или к **директории** с логами.

```bash
# Анализ одного файла
python log_analyzer.py access.log

# Анализ всех логов в директории
python log_analyzer.py ./logs

# Указать директорию для json-файлов со статистикой
python log_analyzer.py ./logs -o ./stats
```

Аргументы:

| Аргумент | Описание |
|---|---|
| `path` | Путь к файлу лога или директории с логами (обязательный) |
| `-o`, `--output` | Директория для сохранения json-файлов (по умолчанию — текущая) |

## Что собирается

По каждому лог-файлу за **один проход** по файлу:

- общее количество выполненных запросов;
- количество запросов по HTTP-методам `GET`, `POST`, `PUT`, `DELETE`, `OPTIONS`, `HEAD`;
- топ-3 IP-адресов, с которых сделано наибольшее количество запросов;
- топ-3 самых долгих запросов: HTTP-метод, URL, IP, длительность и дата/время запроса.

## Результат работы

Для **каждого** обработанного файла формируется отдельный json-файл со статистикой
(имя — `<имя_лог_файла>.json`, например `access.log.json`) и отдельный вывод в терминал.

## Особенности реализации

- Вся статистика собирается за один проход по файлу (файл может быть очень большим).
- Строки, не соответствующие формату лога, пропускаются.
- Топ самых долгих запросов хранится в куче (`heapq`) фиксированного размера,
  поэтому память не зависит от размера лога.
